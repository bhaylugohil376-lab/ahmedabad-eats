# 🍴 Ahmedabad Eats

## Discover. Explore. Enjoy.

**Ahmedabad Eats** is a food discovery website created to help people explore restaurants, food places, cuisines, menus and locations across Ahmedabad, Gujarat.

---

## 🌟 About the Project

Ahmedabad Eats brings useful restaurant information together in one simple and mobile-friendly website.

Visitors can explore restaurants, search for food and cuisines, view menus, check restaurant details and find locations using Google Maps.

The project is designed with a clean, modern and easy-to-use interface.

---

## ✨ Features

### 🔍 Restaurant Search
Search restaurants, cuisines and food items quickly.

### 🍽️ Restaurant Discovery
Browse featured restaurants and discover different food options around Ahmedabad.

### 🥘 Cuisine Categories
Explore different categories such as:

- Gujarati
- North Indian
- South Indian
- Italian
- Vegetarian

### 📋 Restaurant Menu
View available menu items and add selected items to the cart.

### 🛒 Food Cart
Add menu items to the cart and view the total amount.

### 📍 Restaurant Details
Check restaurant address, contact information and other available details.

### 🗺️ Google Maps
View restaurant locations and Ahmedabad locations using Google Maps.

### 📱 Mobile Friendly
The website is designed to work on mobile phones, tablets and desktop devices.

### 🌓 Modern Design
Clean layout, restaurant cards and responsive design provide an easy browsing experience.
